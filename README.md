📋 Описание
Программа предназначена для мониторинга и автоматического завершения процессов Windows Modules Installer (TiWorker.exe и TrustedInstaller.exe), которые иногда могут вызывать проблемы с производительностью системы из-за постоянных перезапусков.

⚠️ Предупреждение
Программа отключает обновления Windows

Некоторые приложения могут требовать работающих служб Windows Update

Используйте только для диагностики и временного решения проблем

Не рекомендуется для постоянного использования на рабочих системах

🔧 Возможности
Автоматическое завершение процессов TiWorker.exe и TrustedInstaller.exe

Остановка связанных служб обновлений Windows

Работа в фоновом режиме с минимальным потреблением ресурсов

Управление через горячие клавиши
